## 装进 DSH

```sh
dsh plugin --profile web add "github:Sakana-yuyu/dsh-plugins"
```

在系统终端运行，不要让 Agent 代跑，然后重启。

打开设置里的「插件库」，或对 Agent 说「帮我找视觉插件」。
